# Integration contract

Standard SPL Token only. SDK uses @coral-xyz/anchor 0.32.1 and web3 1.98.4. Program with job PDA seeds [job, creator, id u64 LE], vault [vault, job]. Protocol agent finalizes exact IDL and SDK interfaces, reports promptly. SDK accepts Connection + Wallet + program ID, exports AgentBondClient and serializeJob. Read DTO amounts/IDs are decimal strings, hashes lowercase hex, timestamps Unix seconds, state uppercase. Anchor statuses include CREATED FUNDED CLAIMED SUBMITTED VERIFIED REJECTED SETTLED CANCELLED REFUNDED. VERIFIED is irreversible approval, only settlement allowed. Creator refund for REJECTED or expiration in FUNDED/CLAIMED/SUBMITTED; never VERIFIED. Deadlines strict ordering claim < submit < verify, server verifies chain Clock.

Shared JobSpec: type csv-analysis, input URL/hash, acceptance with numeric columns and anomaly rule. Worker/verifier use independent computation. Artifact JSON with inputHash, rowCount, columns summary and anomalies. SDK exposes createJob, fundJob, claimJob, submitWork, approveWork, rejectWork, settleJob, refundJob, cancelJob, getJob, listJobs, watchJob. Coordinate exact argument types directly.

API port 4100: /health /jobs /jobs/:address /agents /stats /jobs/:address/events /jobs/:address/artifacts. Metadata explicit local storage, chain authority. UI API endpoint env NEXT_PUBLIC_API_URL default http://localhost:4100. CORS allowed web http://localhost:3000. Never fake chain data. GET /config returns programId, mint, network, rpcUrl; /jobs returns {jobs:[],error?}; /agents returns {agents:[]}; /stats returns actual counts. POST /auth/challenge, authenticated registration and metadata. UI signing via SDK direct chain. Local demo manifest artifacts/demo.json includes transactions, balances, jobs, metadata and agent public keys; API reconciles chain.
